# Каталог + торренты (запросы игр)

Как это работает: в каталоге остаются только игры, у которых есть раздача на rutracker. Кнопка «Запросить» отправляет magnet-ссылку в ps4torrent
(он должен быть версии не ниже 2.1.0.1 и запущен). Файл .torrent с личным ключом на консоль не попадает - только magnet.
Удаление запроса убирает только запись из списка; сам торрент и скачанные файлы удаляются в торрент-клиенте.
Каталог работает офлайн. Запросы, сделанные без сети, ждут: ps4torrent повторяет попытки сам. Статусы в списке запросов обновляются клавишей {S}.

## Подготовка данных на ПК
1. `python tools/rutracker_table.py rutracker-XXXX.xml.xz ps4_games.csv` - таблица раздач ветки PS4 (с адресами обложек и скриншотов). Долго (30-60+ минут).
2. `python tools/merge_torrents.py data ps4_games.csv` - вносит поля раздач в `data/catalog.json`, игры, которых нет в магазине Sony, добавляет
   с обложкой и скриншотами в `data/catalog.pak` (ключ `x`). Резервная копия: `catalog.json.bak`. Безопасно запускать повторно.
   Ключ `--no-media` - без скачивания картинок.
3. Собрать пакет: `cd pkg; make full`.

Выбор раздачи для игры: сначала с русским, потом новее. Игры без кода диска идут в конец списка.
