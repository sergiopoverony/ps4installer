# Жизненный цикл: приложение ↔ служба

Код приложения: `pkg/src/service.cpp` (клиент службы), `pkg/src/ui.cpp` (экраны и действия). Приложение и служба — **разные процессы**,
связь только по HTTP на `127.0.0.1:8284` (клиент `pkg/src/httpc.cpp`, `net.cpp`).

## 1. Запуск службы из приложения
При старте приложение проверяет службу (`SVC_CHECK` → `SVC_STARTING` → `SVC_OK` / `SVC_NO_LOADER` / `SVC_FAIL`):

1. `service_query()` — `GET /health`, берётся `version` и `fw` (первая цифра версии прошивки).
2. Если служба не отвечает **или её версия ≠ версии приложения (`APP_VERSION`)** — приложение отправляет ELF службы
   (`service_send_payload`): файл лежит внутри PKG как `/app0/assets/misc/ps4installerd.elf`, отправляется по TCP на
   **порт 9090** (GoldHEN BinLoader) на `127.0.0.1`.
3. Если порт 9090 недоступен — `SVC_NO_LOADER`, на экране: включить в GoldHEN «Servers settings → Enable Payloader Server»,
   затем нажать Квадрат (повтор).
4. После отправки приложение ждёт ответа `/health` с нужной версией до ~15 секунд (30 попыток по 0.5 с). Не дождалось — `SVC_FAIL`.
5. Один раз за запуск приложения (`g_autorunTried`) ставится **автозапуск службы** (`service_install_autorun`): ELF копируется в
   `/data/payloads/ps4installerd.elf`, а в `/data/GoldHEN/payloads.ini` в секцию `[AutoRun]` добавляется строка
   `/user/data/payloads/ps4installerd.elf = 1` (если её там нет). Так GoldHEN сам запускает службу после перезагрузки консоли.
   Два пути для одного файла — не ошибка: приложение пишет под `/data/...` (песочница), а GoldHEN ищет по `/user/data/...`.

Новая служба при старте сама просит старую завершиться (`POST /quit`) — копии не накапливаются.
Для разработки службу можно отправить прямо с ПК: `make send` в корне (`nc -q0 192.168.0.24 9090 < build/ps4installerd.elf`).

## 2. Список игр
- `service_scan()` → `GET /scan` (со `fresh=1` по кнопке «Квадрат»). Все файлы сразу.
- `build_games()` (`pkg/src/games.cpp`) группирует файлы по Title ID: одна плитка на игру; патчи, DLC и русификаторы считаются
  и показываются пометками (значки в углу плитки). Плитка существует только если есть **основной файл игры**.
  Копии с одним Content ID/типом/размером (диск и флешка) считаются один раз.
- Имя на плитке — `TITLE` из PKG; в каталоге игр картинки и описания берутся из `catalog.pak` по Title ID (запасной поиск по названию).
- «Установлено» определяется по `GET /installed` (Title ID есть на консоли).

## 3. Установка
1. Крест на плитке → окно игры. Приложение берёт `service_free()` (`GET /free`) и `install_files(game, fw)` — файлы к установке
   (backport отфильтрован при прошивке >9; порядок: игра → патчи → DLC → русификаторы). «Нужно места» = их сумма.
2. Если места не хватает (`need > free`) — предупреждение, Крест не работает.
3. Крест → `service_install(paths)` → `POST /install`. Успех — открывается окно «Очередь установки»; приложение запоминает
   состав очереди (`g_queuedFiles`, `g_queuedTitle`) и ставит `g_instActive = true`.
4. Пока `g_instActive`, раз в секунду `GET /status`: каждая строка — файл с пометкой (основной/патч/DLC/русификатор), проценты
   `transferred/length`, статус. Общий процент считается по размерам, показывается и в шапке («Идёт установка: N%»).
5. Когда служба вернула `state != running` — `g_instFinished = true`: в окне «Готово! Установка завершена.» (при ошибках — текст
   причины). Круг скрывает окно во время установки (установка продолжается).
6. Пока идёт установка, можно добавлять другие игры в очередь (повторный `POST /install`).

## 4. Удаление
- **Установленную игру** (вкладка «Установленные игры», Треугольник → подтверждение): `service_uninstall()` → `POST /uninstall`.
  Служба вызывает `sceAppInstUtilAppUnInstall(title_id)` из `libSceAppInstUtil.sprx` (перед этим `sceAppInstUtilInitialize`;
  код `0x80A30018` значит «уже инициализирована» и нормален). Во время установки отвечает `409 busy`. Самого магазина (`OFST00001`) удалить нельзя.
- **Файлы PKG с носителя** (вкладка «Доступные игры», Треугольник → подтверждение): `service_delete_files()` → `POST /delete_files`
  для всех файлов игры; потом список перечитывается (`g_freshScan`).
- Окно подтверждения открывается кнопкой, а ввод в том же кадре игнорируется (`g_skipDeleteInput`) — иначе Круг, открывший окно, сразу бы его закрыл.

## 5. Запуск игры
Крест в «Установленных играх» → `POST /launch` → `sceSystemServiceLaunchApp(title_id, NULL, &{size,userId=0xFF,...})` из
`libSceSystemService.sprx`. Подтверждено на консоли.

## 6. Потоки и блокировки
- Приложение: загрузка списков идёт в отдельном потоке `pthread` (`load_worker`), главный поток только крутит индикатор; ввод в это время игнорируется.
- Служба: HTTP-сервер принимает соединения, установка идёт в отдельном рабочем потоке очереди (`installer::worker_main`), общие данные — под `std::mutex`.
  `/scan` защищён мьютексом (одно сканирование за раз) и кэшем 30 с.

## 7. Язык
Тексты интерфейса — файлы `pkg/assets/misc/lang_<код>.txt` (`ru`, `en`); язык берётся из настроек консоли
(`sceSystemServiceParamGetInt` с параметром 1), либо выбран вручную в меню (кнопка Options), выбор запоминается в `/data/ps4installer_app/lang.txt`.
Тексты ошибок службы (поле `detail` / `message`) пока русские и не переводятся.
