# Документация: как PS4 Installer устанавливает PKG

Эта папка написана для другого агента (или человека), которому нужно понять и повторить установку PKG на PS4
или доработать установщик. Читать по порядку:

| Файл | О чём |
|------|-------|
| [INSTALL_OVERVIEW.md](INSTALL_OVERVIEW.md) | Общая картина: из каких частей состоит система и путь одного PKG от диска до установленной игры |
| [BGFT_INSTALL.md](BGFT_INSTALL.md) | Самое важное: как вызывается системная установка (libSceBgft): загрузка, структуры, функции, прогресс, ошибки |
| [PKG_PARSING_AND_PLANNING.md](PKG_PARSING_AND_PLANNING.md) | Разбор заголовка PKG, проверка «недокачан», допустимые пути, порядок установки (игра → патчи → DLC → русификаторы) |
| [SERVICE_API.md](SERVICE_API.md) | HTTP-интерфейс службы (payload) на порту 8284: все запросы и ответы |
| [APP_AND_SERVICE_LIFECYCLE.md](APP_AND_SERVICE_LIFECYCLE.md) | Как приложение (PKG) запускает службу, следит за установкой, удаляет игры и файлы |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | Известные ошибки, коды, что уже ломалось и чем лечилось, что не проверено |

Окружение, на котором всё проверялось пользователем: PS4, прошивка 13.02, GoldHEN 2.4b18.12, консоль 192.168.0.24.
Что на консоли подтверждено, а что написано только по чтению исходников — отмечено в тексте словами «проверено на консоли» /
«не проверено».

Исходники, о которых идёт речь:
- `src/` — служба `ps4installerd` (payload ELF, собирается ps4-payload-sdk): `main.cpp`, `http.cpp`, `installer.cpp`, `platform.cpp`, `pkg.cpp`, `json.cpp`, `log.cpp`;
- `pkg/src/` — приложение с интерфейсом (PKG, собирается OpenOrbis): `ui.cpp`, `service.cpp`, `games.cpp`, `catalog.cpp`, `i18n.cpp`;
- `tests/` — проверки на ПК (`make test`), служба собирается там с `-DHOST_TEST` и «заглушками» вместо вызовов консоли.
