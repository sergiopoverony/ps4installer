# Известные проблемы и что не проверено

## Что уже ломалось и чем лечилось
| Симптом | Причина | Решение |
|---------|---------|---------|
| Служба падает с сигналом 11 внутри `init` BGFT, консоль зависает | статический буфер / malloc как куча BGFT | куча из `mmap` (1 МиБ, зануление) + метка `bgft_init_<версия>.marker`: после аварии init пропускается |
| `init` возвращает `0x80990001` после замены службы | BGFT в процессе уже инициализирован старой копией | считать успехом |
| Регистрация возвращает `0x80990015` | система занята | повторять до 30 раз с паузой |
| Регистрация возвращает `0x80990088` | пакет уже установлен | не ошибка; статус `already_installed` |
| Установка «зависла» | загрузка не двигается 180 с | `failed: установка не продвигается` |
| PKG приложения не собирается: `Sequence contains no elements` (PkgTool) | новая папка внутри `assets/` | файлы кладите в уже существующие папки `assets/misc`, `assets/images`, `assets/fonts` |
| Приложение при выходе падает (CE-34878) | вызывался обычный `exit(0)` (предположительно) | выход через `sceSystemServiceLoadExec("exit", NULL)` |
| Окно подтверждения закрывается сразу | та же кнопка открыла и закрыла | флаг `g_skipDeleteInput` / `g_skipConfirmInput` |
| 403 от магазина-источника при сборе каталога | блокировка по IP | собирать через прокси (это про `tools/fetch_catalog.py`, не про установку) |

## Что НЕ проверено на консоли
- Раскладка структур BGFT проверена чтением открытых заголовков и работой на прошивке 13.02 (установка идёт), но **другие
  прошивки не пробовались**.
- Достаточность проверки места «размер PKG против свободного места `/user`» — реальный размер установленной игры может быть больше.
- Определение недокачанного торрента по 49 пробам (порог 6 нулевых): если не докачана малая часть файла, пробы могут её пропустить.
- Появление значка в уведомлении «Установлено» (`notify_icon` с путём `/user/appmeta/<TITLE_ID>/icon0.png`).
- Пути `param.sfo` установленных игр на всех прошивках (`/user/appmeta/...`, `/system_data/priv/appmeta/...`, `/user/app/.../sce_sys/param.sfo`).

## Где смотреть при ошибке
1. Журнал службы: `/data/ps4installer/log.txt` (строки `bgft ...`, `install ...`, `enqueue: ...`, `scan: ...`).
2. `GET http://<консоль>:8284/health` — версия, прошивка, найденные функции BGFT.
3. `GET http://<консоль>:8284/status` — задачи, статусы, последние 15 строк журнала.
4. Журнал приложения (строки `ui: ...`, `service: ...`).
5. Уведомление на экране консоли `ps4installer: error 0x........ <TITLE_ID>`.

## Проверка на ПК без консоли
`make test` в корне репозитория: служба собирается с `-DHOST_TEST`, BGFT и системные вызовы заменены заглушками (переменные
окружения `FAKE_INSTALLED`, `FAKE_APPMETA`, `FAKE_LAUNCH_LOG`, `FAKE_UNINSTALL_LOG`, `FAKE_FREE_BYTES`, `FAKE_TOTAL_BYTES`),
тесты создают настоящие PKG-заголовки (`make_pkg` в `tests/test_service.py`) и ходят в HTTP. Так проверяются порядок установки,
пропуски, очередь, места и ошибки.
