# Что сделать позже

## Языки интерфейса
- Язык берётся из системного языка консоли. Поддерживать все языки PS4, как в примере (ps4hddtools), а не только ru / pl / en: ребёнок может начать учить любой другой (например, испанский).
- Добавить новый язык = добавить один файл языка, без правки кода.
- Если языка нет в списке - английский.
- Предусмотреть ручную смену языка в приложении (поверх системного).
- Все надписи и подсказки - в отдельном файле языков; при польском всё по-польски.
- Метку «РУС» на плитке позже, возможно, заменить флажком.

## Очередь установки
- Дать добавлять в очередь другие игры, пока идёт установка (сейчас служба отвечает «busy»). В приложении у карточки показывать «в очереди».

## Окно установленной игры
- Обложка, 4 скриншота, описание (из catalog.pak), Крест - запустить игру, Круг - закрыть.
- Запуск игры по title_id - способ не проверен.

## Пометки вместо текста
- «УЖЕ УСТАНОВЛЕНА», «РУС», «патч», «DLC» - заменить значками.
- Текст уведомления «Установлено» (на английском «Installed») - в файлы языков.

## Красивости
- Вместо надписи про сканирование дисков показывать анимацию: полоску прогресса, крутящийся значок или переворачивающиеся песочные часы.

- Кнопка Options (меню): навесить функционал позже (меню настроек: язык и т.д.). Пока кнопка ничего не делает.

- Каталог игр: фильтры под шапкой (по каким признакам - решить: например, есть русский, число игроков, только офлайн). Алфавитная полоса уже есть.
- Запрос на игры: СДЕЛАНО - см. tools/TORRENTS.md. Осталось проверить на консоли.
